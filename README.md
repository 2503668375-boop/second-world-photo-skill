# 第二世界摄影二创

让摄影中的水波、布料、枝条、倒影、光影与纸面上的绘画自然相通。

这是一份中文创作技能，供支持 `SKILL.md` 的智能体使用。它把构思、中文生图提示、编辑迭代和画面验收连成一个工作流程。它需要所在环境提供读图与图像生成／编辑能力，本仓库不附带模型或接口密钥。

## 核心原则

**边界本身要解释照片。**

海浪沿水势伸出，布料沿褶皱垂落，倒影沿原来的光带继续。纸面与摄影围绕同一次动作组织，人物在清楚的接触点参与其中。每张照片都重新寻找合适的形状，不默认使用“撕一个角＋放一个小人”。

- 从最有辨识度的视觉结构出发，保留原图主体和真实关系。
- 摄影与纸面形成完整场景，跨界处有连续的方向、材质和接触。
- 照片中的云、水、布料等材料可自然延伸为同色绘画；新增人物与普通道具默认采用极简黑白线稿。
- 纸面接近白色、略暖、纹理很轻；留白与动作互相照顾。
- 缩略图上能读懂发生了什么；默认配一句与本图有关的简短英文手写旁白。

默认竖版 3:4；具体比例与上下占比服从用户要求。上下区域即使各占一半，也要通过结构贯通。

## 使用

安装后，可以直接说：

> 使用 $second-world-photo 处理这张照片。先找到最有辨识度的结构，再让它自然跨入纸面。纸面浅一点，跨界材料可以延续原色；人物用极简黑白线稿并真正与照片互动，配一句简短英文手写旁白。

已有版本需要优化时：

> 使用 $second-world-photo 优化这版海报。保留成功的构思，重新设计与照片材质有关的边界，检查接触点、主体大小和留白。

批量制作时：

> 使用 $second-world-photo 把这些照片做成一组海报。每张独立读图，共用清爽气质；边界和动作随各自的结构变化。

只想要提示词时：

> 使用 $second-world-photo，只输出这张照片的中文生图提示词，先不要生成图片。

## 安装到 Codex

把这个仓库作为一个完整文件夹放入以下任一位置：

- 个人技能：`~/.agents/skills/second-world-photo`
- 项目技能：`项目目录/.agents/skills/second-world-photo`

已登录且有仓库访问权限时，也可以使用：

```sh
mkdir -p ~/.agents/skills
gh repo clone 2503668375-boop/second-world-photo-skill ~/.agents/skills/second-world-photo
```

如果目标已经存在，先检查其内容，不要直接覆盖。文件夹根目录应能看到 `SKILL.md`。

也可把仓库保存在长期存储目录，并在技能目录中创建指向它的符号链接。避免在多个可发现目录重复安装同名技能。安装位置与符号链接支持见 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

安装后，在支持技能的环境中选用 `second-world-photo`，或按上面的方式调用。文件校验通过只说明安装结构有效；实际图片仍需逐张查看。

## 使用边界

仓库只包含原创方法说明与文字示例，不收录用户原片、第三方参考截图或生成海报。使用者应根据自己的图片与授权范围制作。

这份技能提供创作判断方法，不保证生成模型每次准确保留摄影细节。声称“原图像素未变”需要实际的合成与核验依据。
